# Security

If you find a security problem in Resonate, for example a way for a skin,
a plugin or a web page to run code or read your Spotify sign-in, please
report it privately:
[Security, Report a vulnerability](https://github.com/livexibot/Resonate/security/advisories/new).

Please do not open a public issue for it. You will get an answer there,
and a fix goes into the next release, which installed copies download by
themselves.

Only the latest release is supported.
